# Automating Contract Intelligence with Doczy.ai on AWS

## Overview

In many industries, especially healthcare and finance, critical business information is locked in unstructured documents such as contracts and agreements. Traditional manual review methods are inefficient, error-prone, and unscalable, leading to significant operational bottlenecks and opportunity costs. Doczy.ai is an intelligent contract interpretation solution developed by AArete that leverages generative AI on Amazon Web Services (AWS) to automate and process such documents at scale, transforming unstructured data into structured, actionable business insights. This case study demonstrates how modern cloud-native AI architecture can solve complex document-intensive business problems. For SREs, its high scalability, accuracy, and monitoring design have important reference value.

## Core Concepts

Doczy.ai's core lies in its patented document understanding engine. Its key concepts and technologies include:

1.  **Smart Chunking**: This is a proprietary text preprocessing algorithm. It not only extracts text but decomposes documents into meaningful, context-aware segments through semantic and keyword search. The algorithm preserves the document's hierarchical structure and one-to-many relationships, for example, identifying associations between a clause and multiple attachments, and using dynamic parameters to maintain logical coherence.

2.  **Dual Clustering Engine**: This is the core of the system's contract understanding. It analyzes each document from two dimensions simultaneously:
    *   **Semantic dimension**: Converts text into embeddings, grouping text blocks with similar meanings but different expressions.
    *   **Structural dimension**: Uses pattern recognition algorithms to analyze clause types, format specifications, table layouts, and hierarchical organization.
    *   Then, through projection algorithms, these two analysis results are compared and synthesized in parallel, forming a unified, rich document model. This ensures the system can not only "read" text but also "understand" the contract's intent and structural context, which is key to achieving 99% accuracy.

3.  **Large Language Model (LLM) and Prompt Optimization**: Building on the dual clustering intelligence, the system uses advanced large language models to generate structured output. It uses few-shot/multi-shot prompting and continuously edits and optimizes prompts based on domain examples and actual outputs, forming a continuous improvement feedback loop to enhance accuracy and adaptability.

4.  **AWS Core Service Stack**: The entire solution is built on a suite of AWS managed services, forming a scalable, secure processing pipeline. Key services include: `Amazon Cognito` (authentication and authorization), `Amazon S3` (object storage), `AWS Lambda` (serverless compute triggers), `Amazon Textract` (OCR and document analysis), `Amazon ECS` (containerized services running AI models), `Amazon Bedrock` (managed generative AI service), `Amazon CloudWatch` (monitoring), and `AWS Secrets Manager` (secrets management).

## Practice

Doczy.ai's architecture design demonstrates an end-to-end, production-ready document intelligence processing pipeline. The practical steps are as follows:

1.  **Document ingestion and authentication**: External users access the system through a secure `Next.js`-based frontend. `Amazon Cognito` handles identity verification and authorization. Users upload contract documents (digital or paper format) directly to an `Amazon S3` bucket, gaining highly durable, highly available storage.

2.  **Text and metadata extraction**: After document upload, an `AWS Lambda` function is triggered, calling `Amazon Textract` to extract text, layout, and metadata information from the document. Textract can handle various document formats, laying the foundation for subsequent processing.

3.  **Smart chunking processing**: The extracted raw text is fed into Doczy.ai's "Smart Chunking" algorithm. This algorithm decomposes flat text into "field groups" that preserve the document's inherent structure and semantic relationships, organizing sequence identifiers and metadata.

4.  **Dual clustering analysis**: The chunked data enters the dual clustering engine, performing semantic analysis and structural analysis simultaneously, and synthesizing both to generate a comprehensive understanding model of the contract.

5.  **Structured output generation**: Based on the context generated by dual clustering, the system determines the document category and uses optimized prompt templates to drive the large language model (called via `Amazon Bedrock`) to generate structured JSON or other format data.

6.  **Data delivery and insights**: The final structured data flows into a `Snowflake` data warehouse, forming a central information repository. This repository supports intelligent dashboards, generating actionable business insights and visual reports, such as contract clause analysis, payment compliance checks, etc.

**Architecture diagram description**: As illustrated in the materials, the entire process starts from the user interface, flows through Cognito authentication into S3. Subsequently, Lambda-triggered Textract, AI processing pipelines on ECS (including smart chunking and dual clustering) execute sequentially. Amazon Bedrock provides large model capabilities. The entire process is monitored by CloudWatch, with Secrets Manager ensuring secret security. Output ultimately converges in the data warehouse (such as Snowflake).

## SRE Key Points

This case study provides valuable reference for SRE practices in automation, reliability, and observability:

*   **Relationship with reliability and observability**:
    *   **High accuracy and scalability**: The system achieves **99% accuracy**, far exceeding the 55% of traditional rule-based systems and the error levels of manual processing. It demonstrates that reliable automation can be achieved through carefully designed AI pipelines (smart chunking + dual clustering). The system has processed over **2.5 million documents (50 million pages)**, proving the architecture's resilience and reliability.
    *   **Comprehensive monitoring**: `Amazon CloudWatch` is integrated for **real-time performance monitoring**, enabling proactive discovery and handling before issues escalate, which is the core of observability and preventive maintenance in SRE practices. SREs can use similar setups to monitor AI model accuracy drift, processing latency, and error rates.

*   **Best practices and common anti-patterns**:
    *   **Best practices**: Adopt managed services (such as Bedrock, Textract) to reduce operational burden; achieve elastic scaling through serverless (Lambda) and containers (ECS); embed security (Secrets Manager, Cognito) into every layer of the architecture; use feedback loops to continuously optimize AI model performance.
    *   **Common anti-patterns**: Relying on single keywords or rules for document parsing (easily missing context), neglecting secondary validation and monitoring of unstructured data output, lacking end-to-end traceability from raw data to business metrics. Doczy.ai's solution effectively avoids these pitfalls through dual clustering and structured output.

*   **Related metrics (SLI/SLO/SLA)**:
    *   **SLI (Service Level Indicator)**: **Document processing accuracy** (such as field extraction correctness rate), **end-to-end processing latency** (time from upload to insight generation), **system availability** (processing pipeline uptime), **throughput** (number of documents processed per week, reaching 250,000 in the case study).
    *   **SLO (Service Level Objective)**: Set based on business requirements, for example, requiring extraction accuracy of key contract clauses (such as payment terms, liability scope) at least 98%, or 95% of document processing to complete within 24 hours.
    *   **SLA (Service Level Agreement)**: As a SaaS provider, AArete may commit to specific service levels for customers, such as 99.9% monthly availability, with corresponding compensation terms.

This case study significantly demonstrates the **SRE enablement** brought by automation: **97% reduction in manual processing time** frees human resources to focus on higher-value judgment and strategic work, rather than repetitive, error-prone data extraction tasks. This directly improves overall operational efficiency and reliability. Related concepts can be referenced in [[reliability-engineering]] and [[observability]].
