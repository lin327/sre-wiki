# Grafana重复行面板的变量切换状态同步问题

## 概述

本文档记录了 Grafana 监控面板在使用“重复行”功能时，由多值变量切换引发的一个状态同步问题。该问题直接破坏了仪表板数据的准确性和实时性，是 SRE 在构建和维护自动化监控看板时需要警惕的典型反模式。当 SRE 基于此类仪表板进行故障排查或容量评估时，过时或错误的数据可能导致误判，延长事件响应时间（MTTR），因此理解此问题的原理与规避方法至关重要。

## 核心概念

1.  **多值变量 (Multi-value Variable)**：Grafana 仪表板中的一种查询变量，允许用户选择多个值（例如，多个数据中心或服务实例）。`includeAll: true` 选项会添加一个“All”选项，代表选择所有可用值。
2.  **行重复 (Row Repeat)**：利用变量值动态创建多个仪表板行的功能。当变量有 N 个选中值时，会生成 N 个对应的行，每行内的面板针对该变量值进行数据过滤和显示。
3.  **过时状态 (Stale State)**：在本问题上下文中，指当驱动重复行的变量值发生改变（特别是从“All”切换到具体值）后，面板的查询或渲染未能完全更新，仍残留着对旧变量值的引用或数据缓存，导致显示的数据与当前选择不符。
4.  **变量重新评估**：理想情况下，变量值的任何更改都应触发其依赖的所有面板（包括重复行及其内部面板）进行完整的查询和重新渲染。本 bug 描述了这一过程的失败。

## 实践

该问题在 Grafana v11.6.1 (可能影响特定版本) 中可复现，复现步骤如下：

1.  **创建仪表板**：新建一个仪表板，并创建一个支持多选的变量（例如 `site`），其 `multi` 属性为 `true`，`includeAll` 为 `true`。
2.  **配置行重复**：在仪表板中添加一个“行”面板，并在其设置中配置 `"repeat": "site"`，使其根据 `site` 变量的值进行重复。
3.  **设置初始状态**：通过 URL 参数或下拉框将变量 `site` 设置为 “All”。此时，仪表板应显示所有数据中心（如 `eqiad`, `codfw`）的行和数据。
4.  **触发问题**：将变量 `site` 的值从 “All” 切换为一个单一值（例如 `eqiad`）。
5.  **观察现象**：此时，虽然行面板会更新（只保留与 `eqiad` 相关的行），但该行内部的监控面板（Panel）仍然显示着来自其他数据中心（如 `codfw`）主机的数据，这便是过时的状态。

**环境与示例**：
-   该问题在一个包含重复行的生产仪表板中被发现，该仪表板用于监控 Wikimedia 负载均衡器。
-   可通过以下公开链接验证：`https://grafana.wikimedia.org/d/000000343/load-balancers-lvs?orgId=1&from=now-12h&to=now&timezone=utc&var-site=eqiad`。

## SRE 要点

*   **与可靠性的关联**：此问题直接损害了监控系统的可靠性。SRE 依赖仪表板进行健康状态检查、异常检测和事件响应。错误的面板数据会误导分析，可能导致错误的决策（如误判故障范围、忽略真实告警）。修复或规避此类问题是保障“可观测性可靠性”的重要一环。
*   **最佳实践与反模式**：
    *   **反模式**：盲目依赖自动化变量更新而不进行最终验证。在执行关键变量切换后，应人工或通过自动化测试抽查面板数据的正确性。
    *   **最佳实践**：
        1.  **版本管理**：在升级 Grafana 版本前，于测试环境充分验证仪表板的复杂功能（如重复、模板）是否正常工作。
        2.  **防御性设计**：对于极其关键的仪表板，考虑在面板标题或查询逻辑中明确显示当前生效的过滤条件（如变量值），以便快速发现不一致。
        3.  **问题上报与跟踪**：一旦发现此类渲染 bug，应立即向上游社区或维护团队报告（如本案例中的 GitHub Issue），并跟踪修复状态。
*   **相关指标 (SLI/SLO/SLA)**：虽然此问题不直接关联传统的 SLI，但它影响了监控数据的**准确性 (Accuracy)** 和 **新鲜度 (Freshness)**，这两个维度是衡量可观测性系统质量的重要内部指标。一个不可靠的仪表板会使任何基于其数据的 SLO 判定失去意义。
*   **事件响应**：在事件响应期间，SRE 会频繁操作仪表板变量以聚焦故障域。此类 bug 可能在事件压力下被忽略，导致排查方向错误。因此，在编写故障排查 Runbook 时，应包含“验证面板数据是否与过滤条件匹配”的步骤。
